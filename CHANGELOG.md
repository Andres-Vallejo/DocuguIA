# Changelog

## 0.2.0 — 2026-11-25

- General document library with user-defined categories and preserved version/status filters.
- CSV, TSV and HTML text/table extraction alongside PDF, DOCX, TXT and Markdown.
- Table rows retain column labels, including combined Word headers and vertical merges.
- Section and page references, local Word-to-PDF previews, and explicit unknown page locations.
- Direct answer first, followed by expandable quotations and links to source pages.
- Fictional examples across operations, inventory and infrastructure, reproducible evaluation, contributor and privacy documentation.

## 0.1.0 — 2026-11-25

- Initial local FTS5/BM25 retrieval and Gemini generation prototype.
- Document version filters, per-document cloud permission, quotation checks, local caching and request limits.
